# Mean-Shift Density Enhancement

Interpreting mean-shift density enhancement for biology.

## Setup

```bash
git clone https://github.com/nveshaan/msde.git
cd msde
uv sync

wget -P ./data https://datasets.cellxgene.cziscience.com/dbb5ad81-1713-4aee-8257-396fbabe7c6e.h5ad
mv ./data/dbb5ad81-1713-4aee-8257-396fbabe7c6e.h5ad ./data/hcla.h5ad
```
